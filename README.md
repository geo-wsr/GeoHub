# 泉盒子的地理可视化平台

一个无需后端的交互式地理可视化平台。当前包含三个教学项目：

- **杜能环交互实验室**：从地租、距离、交通和市场位置解释农业区位。
- **Dijkstra 最短路径实验室**：编辑加权图，逐步观察优先队列、距离表、
  前驱表、松弛和路径回溯。
- **大气水平运动受力实验室**：用原生 SVG 和二维向量求解气压梯度力、地转偏向力、
  惯性离心力与摩擦力的实时平衡。

平台首页默认打开实验库；两个项目使用独立 Hash 路由，构建后可直接部署到
GitHub Pages 等静态托管环境。

| 项目 | 入口 | 核心视图 |
| --- | --- | --- |
| 杜能环 | `#von-thunen` | SVG 圈层地图 ↔ 竞租曲线 |
| Dijkstra | `#dijkstra` | 可编辑 SVG 网络 ↔ 算法事件状态 |
| 大气水平运动 | `#atmosphere` | 四力矢量 ↔ 平衡风与辅助曲线 |

### 算法模块

纯算法位于 `src/dijkstra/dijkstra.ts`，不依赖 React：

```ts
compileDijkstra(graph, start, target): DijkstraRun
```

执行过程先生成不可变事件序列，再由播放器逐步消费。每个事件保存完整快照：

```ts
{
  dist,
  prev,
  visited,
  queue,
  activeNode,
  activeEdge,
  edgeState
}
```

这保证“下一步/上一步”不只移动文本，而是恢复同一时刻的图、表格、队列和伪代码行。

```text
dist[s] = 0; dist[v] = ∞ for v ≠ s
pq = {(0, s)}
while pq not empty:
    u = extract_min(pq)
    if u is visited: continue
    mark u visited
    for each edge (u, v, w):
        if dist[u] + w < dist[v]:
            dist[v] = dist[u] + w
            prev[v] = u
            push (dist[v], v) into pq
```

事件类型与伪代码行为：

| 事件 | 含义 | 同步伪代码 |
| --- | --- | --- |
| `INIT` | 起点设为 0，其余为 ∞，起点入队 | 1–2 |
| `EXTRACT_MIN` | 从优先队列取出最小项 | 4 |
| `SKIP_VISITED` | 惰性删除：取出已访问节点的旧记录 | 4–5 |
| `VISIT_NODE` | 标记节点已访问并确认距离 | 6 |
| `EXAMINE_EDGE` | 计算 `dist[u] + w` 并检查候选边 | 7–8 |
| `RELAX_SUCCESS` | 更新距离与前驱 | 9–10 |
| `PUSH_QUEUE` | 新距离入队 | 11 |
| `RELAX_FAIL` | 候选距离不小于现有值，不更新 | 8 |
| `UNREACHABLE` | 队列耗尽后终点仍为 ∞ | 3 |
| `FINISH` | 搜索结束，可生成路径结果 | 3 |

实现要点：

- 优先队列按距离、再按节点标签稳定排序。
- 允许同一节点存在多个队列项，已访问节点再次被取出时产生 `SKIP_VISITED`。
- 只有严格更短的候选会更新 `dist` 与 `prev`；等长路径不替换已有前驱。
- 有向图只遍历 `from → to`；无向图在邻接表中同时加入两个方向。
- 负权边在编译事件序列前直接拒绝，避免产生看似正确但理论上无效的结果。

### 项目二已知限制

- 只求单一源点的最短路径；不实现负权、负环、所有等长路径、K 短路或多目标优化。

- 教学图的距离和布局是示意值，不代表真实道路网络或测绘结果。
- 编辑状态只保存在当前浏览器会话，刷新后恢复默认多分支示例。

## 项目三：大气水平运动受力实验室

主题为“大气水平运动的受力与风平衡：气压梯度力、地转偏向力、惯性离心力、
摩擦力”。页面不包含关卡、积分、评分或通关机制；主图、公式、平衡读数、
纬向曲线和风偏角指针都由同一份物理状态驱动。

入口：

```text

```

### 功能

- **四力实时矢量合成**：气压梯度力、地转偏向力、惯性离心力、摩擦力和风速全部以
  原生 SVG 箭头绘制；滑块改变后立即重算。悬停或键盘聚焦力箭头可读取公式、数值和
  方向解释。
- **两种等压线几何**：平行等压线与圆形等压线。圆形模式可切换低压/高压中心，
  拖动中心移动整个气压场；拖动空气质点可改变曲率半径。
- **南北半球**：北半球地转偏向力指向速度右侧，南半球指向左侧；纬度到 0° 时
  `f` 和地转偏向力同时归零。
- **自由与反算风速**：自由模式直接调节风速和风向；平衡模式通过二维牛顿迭代
  反算使合力趋近零的风速和方向。
- **四组教学预设**：地转风、梯度风（低压）、梯度风（高压）、边界层风。
  载入预设后仍可继续修改任一参数。
- **平衡状态**：实时显示合力大小、风向、风力夹角和状态标签；接近零合力时显示
  地转平衡、梯度风平衡或边界层平衡。
- **辅助图**：地转偏向力–纬度曲线、风与等压线夹角的指针图，均与主图共用当前参数。
- **亮色/暗色主题**：沿用平台纸白、宋体标题和细线边框语言，以低饱和气象蓝作为
  主操作色；暗色模式使用独立蓝黑纸面、浅蓝控件和适配后的事件颜色。
- **移动端**：参数面板默认收起为抽屉；主图、公式与辅助图保持单列，390px 宽度
  无横向溢出。

### 公式与计算

所有加速度均采用单位质量水平力，单位为 m/s²：

```text
F_p = -(1/ρ)∇p
G = (1/ρ)(Δp/Δn)
F_c = -f k × V,  f = 2Ω sinφ
C = V²/R
F_f = -k V
F_net = F_p + F_c + C + F_f
```

界面中的 `Δp/Δn` 以 hPa/100 km 输入，代码先换算成 Pa/m，再除以空气密度。
北半球以速度右侧为正的地转偏向方向，南半球取反。圆形等压线时，低压中心的
气压梯度力指向圆心，高压中心背离圆心；惯性离心力始终沿曲率半径向外。

#### 平衡反算

求解未知二维速度向量 `V=(u,v)`：

```text
F(V) = F_p + A V + (|V|²/R)e_r - kV = 0
```

其中 `A` 是地转偏向旋转矩阵。实现先按气压梯度方向与半球选择地转切向作为初值，
再使用带回溯线搜索的二维牛顿迭代。若雅可比矩阵接近奇异或参数不存在零合力，
页面标记“平衡近似”，不会把近似值伪装成严格解。

#### 高、低压梯度风的差异

在无摩擦圆形等压线中：

```text
低压：G = fV + V²/R
高压：V²/R = G + fV
```

惯性离心力都向外，但相对气压梯度力在高、低压中方向不同，因此平衡风速不同。

### 四个预设

| 预设 | 几何与参数 | 建议观察 |
| --- | --- | --- |
| 地转风 | 平行等压线，45°N，无摩擦 | 风速近似平行等压线，两力抵消 |
| 梯度风低压 | 圆形低压，42°N，`R=1000 km` | 北半球逆时针环流，三力平衡 |
| 梯度风高压 | 圆形高压，38°N，`R=1200 km` | 北半球顺时针环流，速度较高 |
| 边界层风 | 圆形低压，40°N，`k>0` | 风斜穿等压线并偏向低压 |

### 已知简化

- 只处理水平单位质量力，不求解垂直运动、完整原始方程组或天气系统演变。
- 不含真实地形、时空变化的密度、非圆形实测等压线和边界层垂直分层。
- 摩擦采用线性拖曳 `-kV`，解释方向趋势，不等同于某地点的定量风预报。
- 等压线间距滑块只改变教学图读图间距；物理气压梯度仍以控制面板数值为准。
- 图上的曲率半径和中心位置用于控制教学几何，并非真实地图坐标或测量结果。

## 计算与算法

### 1. 作物竞租

对于作物 `i`：

$$
R_i(d)=y_ip_i-y_ic_i-y_itd
=\underbrace{y_i(p_i-c_i)}_{a_i}
-\underbrace{y_it}_{b_i}d
$$

代码中：

```ts
a = crop.yieldPerHa * (crop.pricePerTonne - crop.costPerTonne)
b = crop.yieldPerHa * freightRate
zeroDistance = a / b
```

单位面积地租 `R` 的单位为元/ha；`y`、`p`、`c`、`t` 的界面单位分别是
t/ha、元/t、元/t、元/(t·km)。

### 2. 交通折减

本实验把到最近一条道路折线的距离 `d_road` 转成位置相关的运费乘数：

$$
m(x)=1-\lambda\exp\left(-\frac{d_{\mathrm{road}}^2}{2\sigma^2}\right)
$$

`lambda` 越大，道路中心折减越强；`sigma` 越大，作用范围越宽。地图只用细实线表示道路，
不绘制半透明缓冲区。对市场 `k`：

$$
d_{\mathrm{eff},k}=d_k\cdot m(x),\qquad
R_i^k(x)=a_i-b_i d_{\mathrm{eff},k}
$$

因此道路旁的有效运费较低，地租梯度变平、耕作边际外推。远离道路时指数项趋近
0，运费乘数恢复为 1。

### 3. 多市场最高竞租

地图用途由以下规则决定：

$$
\text{land use}(x)=
\arg\max_{i,k}\left(0,\;R_i^k(x)\right)
$$

若所有候选地租都不高于 0，则该位置显示为未耕作。曲线面板一次观察一个市场，
避免六个作物乘多个城市的曲线全部堆在一起；市场名称可在曲线面板切换。

### 4. SVG 圈层生成

1. 在视口内建立约 70–150 × 60–120 的采样网格。
2. 对每个采样点计算每个作物在所有市场中的最高地租。
3. 对作物 `i` 构造连续优势场：`R_i - max(0, 其他作物最高地租)`。
4. 用 Marching Squares 对优势场的零等值线插值并追踪闭环。
5. 每个闭环写入原生 SVG `<path>`，使用 `evenodd` 填充规则；道路和多城市影响会
   自然地产生拉伸、合并和竞争边界。

绘制地图前先根据当前最大竞租半径、全部市场和道路端点计算统一比例尺，使所有圈层
完整落在视口内；屏幕坐标与模型坐标之间通过相机反变换保持一一对应。

曲线面板同样由公式采样绘制。点击“实际地租”后，深色粗线显示当前所选市场的作物包络；
有多个市场时，再叠加同一剖面上的全市场最高地租。地图指针与曲线使用相同的距离、
运费率和道路折减函数，因此地图上的道路或城市变化会立即反映到曲线中。

### 5. 集约程度演算

为避免只讨论“种什么”而忽略“投入多少”，页面使用递减边际收益函数：

$$
q_i(k)=1.6y_i(1-e^{-k}),\qquad
\pi_i(k,d)=(p_i-t_{\mathrm{eff}}d)q_i(k)-wk
$$

其中 `k` 为投入强度指数，`w` 为单位投入价格。令边际收益等于投入价格：

$$
(p_i-t_{\mathrm{eff}}d)1.6y_ie^{-k}=w
\quad\Longrightarrow\quad
k_i^*(d)=\max\left\{0,\ln\frac{(p_i-t_{\mathrm{eff}}d)1.6y_i}{w}\right\}
$$

页面会沿所选市场向东剖面实时计算 `k_i^*`、最优单产和净收益。距离增加会降低净价，
从而压低投入强度；道路影响降低有效运费，则会使集约带向外延伸。

## 交互说明

- 拖动“全市场运费率”或任一作物的 `y_i`、`p_i`、`c_i`，观察并排的地图和曲线同步更新。

- 点击“添加城市”，再点击地图放置新市场；侧栏中的竞争市场也可删除。

  “重置参数”恢复当前场景的模型参数。

  操作前的模型与地图几何。

- 帮助弹窗支持 `Esc` 关闭，并对键盘焦点做基本约束。

## 已知限制

- 这是解释机制的示意地图，不是真实地理投影，也没有地形、河流、土壤和行政区边界。
- 道路采用可绘制的折线及距离衰减，不含道路等级、通行能力、拥堵、绕行或路径选择；
  移动模式平移整条道路，不提供逐节点编辑。
- 所有市场使用相同作物价格与运费率，不模拟供需反馈、规模经济、税收、土地制度、
  多年生资产或消费偏好。
- 集约程度采用示意性的指数型生产函数 `1.6y_i(1-e^{-k})`，主要用于展示边际投入递减，
  不代表具体作物的田间试验参数。
- 地图等值线来自浏览器网格采样，精度服务于教学；不应把像素边界当作测绘或规划依据。
- 为保证所有圈层完整可见，地图会根据当前最大竞租半径自动调整显示比例；因此不同参数下
  的像素尺度不可直接横向比较，距离与地租仍应读取数值标注。
- 城市位置、参数与曲线显隐不写入后端，刷新页面后回到单中心基础场景。
