# 外链资料的存放约定

把**不常变动、下载量大**的资料（讲义、期末真题、图集等）放在这个目录，它们会随前端一起发布，
由 GitHub Pages 的 CDN 直接分发 —— **完全不占用后端对象存储的 1 GB 配额**，
而且 Pages 每月 100 GB 的流量额度比对象存储宽松得多。

## 怎么用

1. 把文件放进本目录，文件名用英文或拼音（避免空格与特殊字符，方便链接与排错）：

   ```
   frontend/public/materials/2025-final-exam.pdf
   ```

2. 提交并推送，等前端部署完成（约 1 分钟），文件地址是：

   ```
   https://www.bnugeohub.cn/materials/2025-final-exam.pdf
   ```

3. 进网站 → 上传资料 → **资料形式选「外链地址」** → 粘贴上面的地址 → 提交。
   资料库里照常显示、可搜索、下载量照常统计，只是文件从 CDN 出，不经过后端。

## 注意事项

- **单文件建议 ≤ 50 MB**（git 单文件超过 100 MB 会被拒绝推送）
- 文件一旦提交就永久留在 git 历史里，删除也仍占空间 —— 所以这里只放"定稿"的资料，
  频繁替换的文件请继续走上传（对象存储）
- 本站发布产物（GitHub Pages）整体不宜超过 ~1 GB
- 用户上传、需要审核、可能被删除的资料**不要**放这里，走正常上传流程
